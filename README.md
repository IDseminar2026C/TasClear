⸻
こんな人のためのアプリです

「毎日同じようなタスクに追われて作業感が強い」「ゲーム（レベルアップやガチャ）が好きで、報酬があると集中できる」デスクワーカーや個人学習者が 一日の始まり・作業前 に「義務感」のあるToDoリストを「RPGのクエスト討伐」に変え、サクサク攻略（クリア）する快感を提供するゲーム感覚ToDoアプリ。`





解決する困りごと
毎日同じようなタスクに追われて作業感が強い」と感じているデスクワーカー


⸻
使い方

１.その日に行いたいタスクを入力
2.	それを達成するたびに撃破ボタンをタップ
3.	経験値が溜まってレベルがアップ

<details>
<summary>記入例を見る</summary>

1.	上の入力欄に、授業名・提出物名・締切日を入力します。
2.	「追加」ボタンを押すと、下のリストに追加されます。
3.	提出し終わったら、左のチェックボックスを押してください。リストの下へ移動します。
4.	入力した内容はブラウザに保存されるので、閉じても消えません。

</details>

AI の使い分け

この作品は、集中講義「生成AIエージェントによるWebアプリ開発入門」で、 
生成AIを使って開発しました。
	使ったAI	何に使ったか
考える・整理する	Gemini	課題の下書きと仕様書の整理
実装する・直す	Claude Code	画面や機能の実装
決める・確かめる	人間（私たち）	AIの提案内容を自分たち好みに添削

AI が出した提案のうち、は私たちの判断で却下しました。 
最終的な動作確認と公開の判断は、すべてチームのメンバーが行っています。

ローカルで動かす方法

このアプリは HTML / CSS / JavaScript だけでできています。 
特別な準備は必要ありません。

1.	このリポジトリをダウンロード（または git clone）します。
2.	index.html をブラウザで開きます。

VS Code で開いている場合は、Live Server 拡張を使うと確認が楽です。
⸻
注意

⁃	データはブラウザに保存されます。別のブラウザや別の端末では引き継がれません。
⁃	ブラウザの履歴やサイトデータを削除すると、データも消えます。
